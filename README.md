# 室内导航 Demo

单文件、零依赖、可离线的室内地图导航演示，纯原生 JavaScript + Canvas 实现，直接用浏览器打开 `index.html`（或部署任意静态服务器）即可。

## 功能

- **三层楼层**：1F / 2F / 3F，默认显示 1F，且默认进入 3D。
- **色块 = 商铺，名称默认显示**：每个色块就是一家店（优衣库、Apple 授权店、海底捞、万象影城…），名称直接标在块上；非当前层以淡色标注，切换楼层即可对照。
- **区域墙体用线块表示**：立面色块 + 深灰蓝描边，屋顶面单独描粗边并加墙脚线；2D 正俯视看不到立面，因此额外画一圈内缩线表示墙厚，任何角度下区块边界都一目了然。
- **不可通行区域已标记**：斜纹 + 深灰实体块，并在块上写明原因——中庭洞口、电动扶梯井道、电梯井、疏散楼梯、设备机房、后勤仓储。点击这些位置会提示具体原因，不会被选为起终点。
- **同层大部分区域可通行**：建筑轮廓内约 81% 的栅格可走，仅扣除上述结构区；三层各自 100% 连通（脚本校验），不会走进去就出不来。
- **电动扶梯按真实几何建模**：提升高度 62 单位（≈8.7 m 层高），水平投影 = 62 / tan30° = 107 单位（≈15 m），倾角 **30.1°**，符合 GB 16899 对公共交通型扶梯的角度要求。桁架、踏面、等距台阶线、两侧扶手带、上下落客平台都画出来了，并标注 E1–E4 与运行方向。
  - **剪刀式布置**：A 井（E1 上行 / E2 下行）只跨 1F⇄2F，B 井（E3 / E4）只跨 2F⇄3F。1F→3F 会先上 A 井、过厅换 B 井，不会沿同一井道折返。
  - **楼板开洞真实化**：扶梯井只在其穿过的楼板上开口，起点层是落在实体楼板上的落客平台。
- **通高客梯**：LT1 / LT2 井道从本层楼板一直画到屋面，轿厢随当前楼层停靠；代价高于扶梯，只有扶梯绕远时 A* 才会选它。
- **2D / 3D 切换**：两种视角各自记忆缩放与平移，互不覆盖。
- **自由旋转**：3D 下单指/鼠标拖动 = 左右旋转 + 上下俯仰（0–83°，可停在任意角度）；双指平移缩放，滚轮以光标为锚点缩放，Shift/右键平移，方向键微调，底部 `⟲ ▲ ▼ ⟳` 支持长按连转，`复位` 回初始机位。
- **双点算路**：点两处生成起点 A、终点 B。10 单位栅格 + 8 邻域 A*，跨层走扶梯或电梯；导航线在跨层段**沿扶梯斜面连续爬升**，而不是竖直跳层。
- **模拟导航**：小人按真实速度行走，斜跑上楼层连续插值（能看到它"坐着扶梯上去"），镜头跟随，到点提示"已到达"。
- **步导清单**：分行显示每层步行距离与「乘电动扶梯上行 1F → 2F」这类指令。
- **图层开关**：商铺色块、不可通行、电动扶梯、客梯、POI、商铺名称可单独隐藏。

## 对外 JS API（集成调用）

页面上所有交互动作都提取成了全局对象 `window.mallNav`，可以直接在自己的业务代码里调用，无需改动渲染逻辑：

```js
mallNav.setViewMode('3');                          // 2D / 3D
mallNav.locate('外婆家', {zoom:1.6});               // 检索并飞过去
const r = mallNav.route('北出入口', '外婆家');       // 一次算路：{meters, minutes, transfers…}
mallNav.setSpeed(1.5); mallNav.start();            // 小人开始行走
mallNav.on('walk', d => console.log(d.progress));  // 事件订阅，on() 返回取消函数
```

- 完整方法、参数与返回值见 **[API.md](API.md)**（视图 / 选点算路 / 模拟导航 / 图层 / 检索定位 / 坐标换算 / 事件 / 状态）。
- 6 个可直接粘贴的联动场景见 **[INTEGRATION.md](INTEGRATION.md)**：搜索框联想导航、楼层导览面板、讲解回放 `seek()`、事件看板与视角记忆、iframe `postMessage` 桥接、多段巡更动线。

## 实现要点

- 自研轨道相机：`rotV()` 做 yaw/pitch 旋转，`proj()` 投影，`unproj()` 解析求屏幕点与楼层平面的交点，任意角度下点击选点都精确。
- 渲染用画家算法：楼层与体块按深度排序，配合背面剔除（`facing()` / `planNormal()`），任意视角遮挡关系正确。
- 路径按整层切段后再做 Douglas-Peucker 抽稀，跨层折点单独由 `verticalWaypoints()` 沿斜面插值，避免斜跑被压平。
- 全部交互用 Pointer Events 统一处理，触屏与鼠标一致；`touch-action:none` 防页面滚动干扰。
