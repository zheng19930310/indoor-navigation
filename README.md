# 室内导航 Demo

单文件、零依赖的室内地图导航演示，纯原生 JavaScript + Canvas 实现，直接用浏览器打开 `index.html` 即可。

## 功能

- **三层楼层**：1F / 2F / 3F，默认显示 1F。
- **2D / 3D 切换**：同一套投影公式，2D 为正交平面，3D 为可自由旋转的立体分层视图。
- **自由视角**：3D 下左右拖动水平旋转（yaw 360°），上下拖动调整俯仰（pitch 0°–84°），可停在任意角度；双指或滚轮缩放，Shift/Ctrl+滚轮也可旋转。
- **双点算路**：点击两处生成起点 A、终点 B，基于网格 A* 求解路径，同层为红色实线，跨层为蓝色虚线，并给出距离、耗时、跨层次数与分步指引。
- **模拟导航**：小人沿路径行走，经过扶梯/电梯时楼层连续插值、自动切换当前层，镜头跟随，支持暂停/继续/重播。
- **图层开关**：可单独隐藏主力店、餐饮、商铺、交通核、扶梯、电梯、POI 等图层。

## 结构

地图几何按参考图抽象：三层共用同一建筑轮廓，包含两处中庭洞口、中央竖向交通核（扶梯 ×2、电梯 ×2）、分区色块与 POI。

- 导航网格：10 单位栅格，仅取可行走点（轮廓内且不在中庭洞口），同层 8 邻域连通，跨层通过扶梯/电梯节点连接。
- 渲染：画家算法按深度排序，配合背面剔除，保证任意视角下不穿帮。

## 说明

几何与色块为示意级重绘，非像素级复刻。若需接入真实数据，可将 DXF / GeoJSON / 室内地图 JSON 转换为 `SHAPE`、`HOLES`、`CORE`、`zones`、`pois` 等结构，算路与渲染逻辑无需改动。
